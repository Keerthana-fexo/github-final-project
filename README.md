# GitHub Final Project

This project is part of the IBM Introduction to Git and GitHub course.

## Description

A simple shell script to calculate simple interest based on principal,
rate of interest, and time period.

## Usage

Run the script:

bash simple-interest.sh

Enter the principal amount, rate of interest, and time period when prompted.

## Formula

Simple Interest = (Principal × Rate × Time) / 100
